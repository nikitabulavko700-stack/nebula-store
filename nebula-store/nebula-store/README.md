# Nebula Store — каталог скинов

Структура:
```
index.json          список скинов (читает приложение)
skins/*.cxskin      сами скины
previews/*.png      превью для карточек
add_skin.py         добавить скин одной командой
```

Добавить скин:
1. В Nebula выбери скин → «Экспорт .cxskin».
2. `python add_skin.py путь/к/файлу.cxskin --tags "неон,стрелка"`
   (id берётся из названия латиницей; для кириллицы задай `--id my-skin`).
3. Закоммить и запушь на GitHub.
